Setup Guide — Getting Your API Keys
Step 1 — Anthropic API Key Required for AI Notes

This key lets the app generate structured notes (action items, decisions, topics) from your transcript.

  1. Go to console.anthropic.com and sign in or create a free account.
  2. Click API Keys in the left sidebar.
  3. Click Create Key — give it any name (e.g. "AI Notetaker").
  4. Copy the key — it starts with sk-ant-
  5. Open Settings above and paste it into the Anthropic API Key field.
Cost: a few cents per session. New accounts include free credits to get started.
Step 2 — OpenAI API Key Required for Meeting / Call mode

This key powers Whisper, which transcribes your recorded audio. Only needed if you use Meeting / Call mode.

  1. Go to platform.openai.com and sign in or create a free account.
  2. Click your profile icon (top right) → API Keys.
  3. Click Create new secret key — give it any name.
  4. Copy the key — it starts with sk-
  5. Open Settings above and paste it into the OpenAI API Key field.
Cost: ~$0.006 per minute of audio. A 20-minute call costs about 12 cents.
Which mode should I use?

Quick Note — uses your browser's built-in speech recognition. Free, no key needed. Best for solo voice memos or dictation in a quiet environment. Chrome only.

Meeting / Call — records audio and sends it to OpenAI Whisper for transcription. Handles accents, crosstalk, and longer recordings much better. Requires an OpenAI key.

Your browser doesn't support the Web Speech API. Please open this file in Google Chrome for Quick Note transcription to work.
